# 🚀 Stkvpn - V2Ray VPN Client

یک اپلیکیشن قدرتمند VPN برای اندروید با قابلیت‌های پیشرفته‌ی دور زدن فیلترینگ.

## ✨ ویژگی‌ها

- **پشتیبانی از پروتکل‌های مختلف**: VLESS, VMess, Trojan, Shadowsocks
- **SNI Tunnel**: تغییر SNI برای دور زدن DPI
- **Domain Fronting**: عبور از فیلترینگ با CDN
- **Desync & Fragment**: تکه‌تکه کردن بسته‌ها برای دور زدن DPI
- **Kill Switch**: قطع خودکار اینترنت در صورت قطع VPN
- **Split Tunneling**: انتخاب اپ‌های خاص برای عبور از VPN
- **Recent Activity**: نمایش تاریخچه اتصالات
- **Backup & Restore**: پشتیبان‌گیری از تنظیمات
- **حالت شب/روز**: انتخاب تم دلخواه
- **راهنمای کاربری**: برای اولین اجرا
